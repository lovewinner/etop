# etop

一个类似 htop 的极简终端监控工具，只关注四项实时利用率：

| 指标 | 说明 |
| --- | --- |
| **CPU** | 整体利用率、历史曲线与进度条 |
| **内存** | 物理内存使用率、Cache/Buffers、Swap |
| **GPU** | 利用率（检测到 GPU 时显示） |
| **显存** | 显存占用率（检测到显存信息时显示） |

界面为纯 curses 实现，无第三方依赖。单 GPU 时每个指标带实时历史曲线；多 GPU 时 GPU 与显存合并为文字列表，逐卡显示利用率和显存。

## 快速开始

```bash
# 直接运行
./etop

# 或者
python3 -m etop_tui

# 安装为命令
pip install -e .
etop
```

要求 Linux + Python 3.9+。若终端不支持 UTF-8，可加 `--ascii`。

颜色按负载分档：低于 60% 绿色、60–85% 黄色、85% 以上红色。分档同时作用于面板标题、进度条以及历史曲线的每一列（因此历史尖峰也会保留自己的颜色）；启动时历史不足会自动拉伸铺满整条曲线。`--once` 在彩色终端下同样着色；256 色终端使用低饱和度的绿/黄/红。若终端不支持颜色，则用加粗/反显区分档位。

## 按键

| 按键 | 作用 |
| --- | --- |
| `q` / `Esc` | 退出 |
| `p` / 空格 | 暂停 / 继续采样 |
| `+` / `-` | 加快 / 减慢刷新（0.25s 步进，范围 0.25–10s） |
| `r` | 清空历史曲线 |
| `h` / `?` | 帮助 |

## 命令行

```text
etop [-d SECONDS] [--once] [--gpu {auto,nvidia,sysfs,none}]
     [--demo] [--no-color] [--ascii] [--version]
```

- `-d, --delay`：刷新间隔，默认 1 秒。
- `--once`：打印一次纯文本快照后退出，适合脚本或非交互环境。
- `--gpu`：GPU 后端，默认自动探测。
- `--demo`：使用合成 GPU 数据，便于在没有 GPU 的机器上预览面板。
- `--no-color` / `--ascii`：关闭颜色 / 使用纯 ASCII 字符。

## 数据来源

- **CPU**：`/proc/stat`，两次采样之间 busy/total 的增量；首帧显示开机以来的平均值。
  `iowait` 计入空闲，与 htop 口径一致。
- **内存**：`/proc/meminfo`。使用量 = `MemTotal - MemAvailable`，并单独展示 Cache/Buffers 与 Swap。
- **GPU**：
  - NVIDIA：`nvidia-smi --query-gpu=index,name,utilization.gpu,memory.used,memory.total,temperature.gpu`；
  - AMD / 其他 DRM 驱动：`/sys/class/drm/card*/device/gpu_busy_percent`、`mem_info_vram_used`、`mem_info_vram_total`、`hwmon/*/temp1_input`。
  - 未检测到 GPU 时自动隐藏 GPU 与显存面板；驱动短暂失败时保留上一帧并标记 `stale`。
- **Load / uptime**：`os.getloadavg()` 与 `/proc/uptime`。

## 多 GPU

检测到多张 GPU 时，不再绘制逐卡进度条，而是把 GPU 与显存合并成一个文字面板，每张卡一行：

```text
┌ GPU / VRAM ───────────────────────────── 4 GPUs ┐
│GPU0  42.0% 1.2/24.0G 5% 54°C                     │
│GPU1  87.0% 19.5/24.0G 81% 61°C                   │
│GPU2  12.0% 4.0/80.0G 5% 38°C                     │
│GPU3  96.0% 68.4/80.0G 85% 72°C                   │
└──────────────────────────────────────────────────┘
```

精简布局下同样每卡一行，显存和温度跟在利用率后面。44x8 时可同时显示 CPU、内存和最多 4 张 GPU；每多一张卡需要多一行，例如 8 张卡至少需要 40x12。

## 终端尺寸

- **完整布局**：约 **44x16** 起，四个面板带边框和历史曲线。
- **精简布局**：空间不足时自动切换为“每项指标一行”（标签 + 进度条 + 百分比 + 关键数值），
  最小 **40x6**。因此在 **44x8** 下仍能同时显示 CPU、内存、GPU、显存四项：

```text
 etop 0.1.0  host  up 2h            14:03
 CPU   ██████▍                      12.4%
 MEM   ███████████▋        61.5%  9.6/15.6G
 GPU   ██████████████████▉  78.9%  52°C
 VRAM  ████████████████▉    93.4%  14.9/16.0G
 q quit  p pause  +/-  r reset  h help
```

多 GPU 时精简布局会把每张卡写成：

```text
 CPU   ██████▍                      12.4%
 MEM   ███████████▋        61.5%  9.6/15.6G
 GPU0   42.0% 1.2/24.0G 5% 54°C
 GPU1   87.0% 19.5/24.0G 81% 61°C
 q quit  p pause  +/-  r reset  h help
```

低于 **40x6** 时显示提示。精简布局用进度条代替历史曲线以节省行数。
