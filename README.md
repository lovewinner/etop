# etop

一个类似 htop 的极简终端监控工具，只关注四项实时利用率：

| 指标 | 说明 |
| --- | --- |
| **CPU** | 整体利用率、历史曲线与进度条 |
| **内存** | 物理内存使用率、Cache/Buffers、Swap |
| **GPU** | 利用率（检测到 GPU 时显示） |
| **显存** | 显存占用率（检测到显存信息时显示） |

界面为纯 curses 实现，无第三方依赖。完整布局下，单 GPU 时每个指标带实时历史曲线；多 GPU 时 GPU 与显存合并为一个面板，逐卡显示利用率柱状和显存/温度文字。精简布局统一使用柱状 + 数值，不绘制曲线。

## 快速开始

```bash
# 直接运行
./etop

# 或者
python3 -m etop_tui

# 安装为命令
pip install -e .
etop
```

要求 Linux + Python 3.9+。若终端不支持 UTF-8，可加 `--ascii`。

```text
│ ... 实时曲线 ...                                                     │
│||                                                            2.7%  │
└──────────────────────────────────────────────────────────────────────┘
┌ MEMORY ────────────────────────────────────────────────────  60.0% ┐
│|||||||||||||||||||||||||||||||||||||||||||||||              60.0%│
│Used 9.4 GiB / 15.6 GiB   Cache 5.8 GiB   Avail 6.2 GiB            │
│Swap 3.3 GiB / 8.0 GiB (40.8%)                                     │
└──────────────────────────────────────────────────────────────────────┘
┌ GPU ───────────────────────────────────────────────────────  88.2% ┐
│|||||||||||||||||||||||||||||||||||||||||||||||||||||        53°C│
└──────────────────────────────────────────────────────────────────────┘
┌ VRAM ──────────────────────────────────────────────────────  93.4% ┐
│||||||||||||||||||||||||||||||||||||||||||||||||||||||       93.4%│

└──────────────────────────────────────────────────────────────────────┘
  q quit   p pause   +/- interval   r reset   h help     1.00s
```

所有指标（CPU、内存、GPU、显存）都使用 htop 风格的彩色 `|` 条。

颜色按 4 档分色：低于 40% 绿色、40–60% 黄色、60–85% 橙色、85% 以上红色。分档同时作用于面板标题、进度条以及历史曲线的每一列（因此历史尖峰也会保留自己的颜色）；启动时历史不足会自动拉伸铺满整条曲线。`--once` 在彩色终端下同样着色；256 色终端使用低饱和度的绿/黄/橙/红（#87AF87 / #D7D787 / #D7AF87 / #D78787），8 色终端会合并中间两档。若终端不支持颜色，则用加粗/下划线/反显区分档位，并使用终端默认背景（不强制黑底）。

## 按键

| 按键 | 作用 |
| --- | --- |
| `q` / `Esc` | 退出 |
| `p` / 空格 | 暂停 / 继续采样 |
| `+` / `-` | 加快 / 减慢刷新（0.25s 步进，范围 0.25–10s） |
| `r` | 清空历史曲线 |
| `h` / `?` | 帮助 |

## 命令行

```text
etop [-d SECONDS] [--once] [--gpu {auto,nvidia,sysfs,none}]
     [--demo] [--no-color] [--ascii] [--version]
```

- `-d, --delay`：刷新间隔，默认 1 秒。
- `--once`：打印一次纯文本快照后退出，适合脚本或非交互环境。
- `--gpu`：GPU 后端，默认自动探测。
- `--demo`：使用合成 GPU 数据，便于在没有 GPU 的机器上预览面板。
- `--no-color` / `--ascii`：关闭颜色（仍使用终端默认背景）/ 使用纯 ASCII 字符。

## 数据来源

- **CPU**：`/proc/stat`，两次采样之间 busy/total 的增量；首帧显示开机以来的平均值。
  `iowait` 计入空闲，与 htop 口径一致。
- **内存**：`/proc/meminfo`。使用量 = `MemTotal - MemAvailable`，并单独展示 Cache/Buffers 与 Swap。
- **GPU**：
  - NVIDIA：`nvidia-smi --query-gpu=index,name,utilization.gpu,memory.used,memory.total,temperature.gpu`；
  - AMD / 其他 DRM 驱动：`/sys/class/drm/card*/device/gpu_busy_percent`、`mem_info_vram_used`、`mem_info_vram_total`、`hwmon/*/temp1_input`。
  - 未检测到 GPU 时自动隐藏 GPU 与显存面板；驱动短暂失败时保留上一帧并标记 `stale`。
- **Load / uptime**：`os.getloadavg()` 与 `/proc/uptime`。

## 多 GPU

检测到多张 GPU 时，GPU 与显存合并成一个面板，每张卡一行：利用率用柱状表示，显存和温度文字统一右对齐。

```text
┌ GPU / VRAM ───────────────────────────── 4 GPUs ┐
│GPU0 |                     38.7/48G(81%) 34°C │
│GPU1                       38.7/48G(81%) 34°C │
│GPU2                       20.2/48G(42%) 33°C │
│GPU3 |||||||||||||||        2.4/48G(5%)  59°C │
└──────────────────────────────────────────────────┘
```

精简布局下同样每卡一行：柱状条 + 右对齐的显存/温度。44x8 时可同时显示 CPU、内存和最多 4 张 GPU；每多一张卡需要多一行，例如 8 张卡至少需要 40x12。

## 终端尺寸

- **完整布局**：约 **44x16** 起，四个面板带边框和历史曲线。
- **精简布局**：空间不足时自动切换为“每项指标一行”（标签 + 柱状 + 右对齐文字），
  最小 **40x4**。**40x4 / 40x5 只显示 CPU 和内存，不显示 GPU/显存**；40x6 起在 GPU 行放得下时显示 GPU。因此在 **44x8** 下仍能同时显示 CPU、内存、GPU、显存四项：

```text
 etop 0.1.0  host  up 2h            14:03
 CPU  ||||||||||                    53.7%
 MEM  ||||                    77/504G(15.2%)
 GPU  ||||||||||                          54°C
 VRAM ||                       1.2/24G(5.0%)
 q quit  p pause  +/-  r reset  h help
```

多 GPU 时精简布局会把每张卡写成：

```text
 CPU  ||||||||||                    53.7%
 MEM  ||||                    77/504G(15.2%)
 GPU0 |                 38.7/48G(81%) 34°C
 GPU1                   38.7/48G(81%) 34°C
 GPU2                   20.2/48G(42%) 33°C
 GPU3 ||||||||||||||||   2.4/48G(5%)  59°C
 q quit  p pause  +/-  r reset  h help
```

40x4 时仅保留 CPU 和内存两行：

```text
 etop 0.1.0  host  up 2h
 CPU  ||||||||||            53.7%
 MEM  ||||              77/504G(15.2%)
 q quit  p pause  +/-  r reset  h help
```

精简布局每项指标占一行，空间富余时在底部留白，不绘制历史曲线；历史曲线仅保留在完整布局中。低于 **40x4** 时显示提示。
